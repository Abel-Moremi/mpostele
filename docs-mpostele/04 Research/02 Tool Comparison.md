# Tool Comparison

## Comparison table

| Tool | Best use | Memory profile | Fit for this project |
| --- | --- | --- | --- |
| Manim | text, graphics, overlays | low | excellent |
| FFmpeg | zoom, pan, composition | very low | excellent |
| Playwright | browser-based motion capture | low | excellent |
| AnimateDiff | AI-generated motion clips | high | poor |
| SVD | video generation from images | high | poor |

## Recommendation

Use code-based motion tools and browser automation first. Avoid heavy local AI video generation unless the hardware is significantly upgraded.
