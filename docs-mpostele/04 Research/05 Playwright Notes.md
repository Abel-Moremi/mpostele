# Playwright Notes

Playwright is used for browser automation, UI capture, and animated webpage interactions.

## Core benefits

- capture actual product pages and interfaces
- automate scroll and interaction sequences
- inject CSS or JavaScript for motion effects
- record visual states without local GPU-heavy video generation

## Typical usage

- open product landing page
- animate hero elements
- scroll through major features
- capture screenshots at each stage

## Best practices

- use consistent viewport dimensions
- record after animations complete
- avoid unnecessary heavy browser tabs or open windows
- keep capture smooth and deterministic
